採用 YouTube IFrame API 在頁面內播放：本週依序播放、整週循環、單本循環及不循環；複習週使用原有對應書單。保留原有打勾紀錄與 Drive 開啟連結，不再依賴 Drive 串流。每本可搜尋、修改網址及還原預設，設定存在目前瀏覽器。

考慮過外連 YouTube 播放清單（無法在原頁編輯及控制每週書單）與內嵌播放器，採後者。使用現有純 HTML/JavaScript，無後端、API key 或新產品依賴。預設影片資料獨立存放，記錄影片標題、頻道及來源；搜尋結果必須對應書名，無可信結果則明確標示待補。

播放器必須可見，支援手機；自動播放受阻時提示點擊播放器。錯誤顯示外開、更換與跳過操作，全部失效不能無限循環跳轉。上一首、下一首、速度、計時停止及播放進度沿用。不得把候選影片的標題匹配當成已完整觀看或保證地區可播。
